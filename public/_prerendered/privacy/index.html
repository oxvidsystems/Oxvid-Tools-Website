Privacy Policy

Last updated: September 24, 2026

Oxvid Tools is built and operated by Oxvid Systems. This policy explains what happens to your data — and, just as importantly, what doesn't — when you use this site.

No account, no registration data. Every tool on Oxvid Tools is available immediately with no sign-up, so we never collect a name, email address or password to let you use the site.

Most tools never leave your browser. Tools in the PDF, Image, Text, Developer, Calculator, Finance, Generator, SEO and Color categories run entirely client-side, using standard browser APIs (Canvas, the File API, and libraries loaded into the page). Whatever you type or upload into these tools is processed on your device and is not transmitted to, or stored on, any server we operate.

Third-party code and fonts. The site loads its typefaces from Google Fonts (fonts.googleapis.com / fonts.gstatic.com); that request goes to Google, which may log standard technical data such as your IP address under its own privacy policy. A handful of tools — the PDF tools, QR Code Generator and Barcode Generator — load a small, well-known open-source library (pdf-lib, pdf.js, jsPDF, qrcode.js or JsBarcode) from a public code CDN the first time you open them in a session. These requests fetch program code only; nothing you type or upload is sent along with them.

Local storage. We store exactly one preference in your browser's local storage: your light/dark theme choice. It stays on your device, is never transmitted anywhere, and you can clear it at any time by clearing your browser's site data.

Cookies and tracking. This site does not set advertising or cross-site tracking cookies, and does not currently run any third-party analytics. If that changes, this policy will be updated first.

The Contact page. The form on our Contact page is not yet wired to a live inbox — submitting it does not send your message anywhere yet. We're noting that plainly here rather than implying otherwise.

Children's privacy. Oxvid Tools is a general-audience utility site and is not directed at children; we do not knowingly collect personal information from anyone, including children.

Changes to this policy. If how this site handles data changes — for example, if we add analytics or a server-side feature — we'll update this page and its "last updated" date.

This policy describes this site's actual behavior as of the date above. It's provided as a good-faith, plain-language summary and isn't a substitute for legal advice specific to your business or jurisdiction.
